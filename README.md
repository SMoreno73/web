# Course AI Tutor privacy site

This directory contains a buildless static site. It uses only HTML and CSS and can be deployed to any static host, such as GitHub Pages, Cloudflare Pages, or Netlify.

## Deploy

1. Replace every bracketed placeholder in `index.html`, `privacy-policy.html`, and `terms-and-conditions.html` with accurate institutional information.
2. Review the Privacy Policy with the responsible privacy, legal, and technical teams. Confirm actual data categories, providers, retention periods, security practices, contact details, and the student age groups served; remove or revise any statement that does not match actual practice.
3. Have the responsible legal representative review the Terms and Conditions, including the disclaimer and limitation template, and confirm that the service description and user requirements match institutional practice.
4. Publish the contents of this directory on a static HTTPS host.
5. Confirm the landing page, `privacy-policy.html`, and `terms-and-conditions.html` load publicly without authentication. Use the stable HTTPS URLs ending in `/privacy-policy.html` and `/terms-and-conditions.html` for the corresponding Meta app fields.

Do not submit either legal page while placeholders remain. The institution is responsible for ensuring both published pages are complete, accurate, and current.
