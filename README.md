# Course AI Tutor privacy site

This directory contains a buildless static site. It uses only HTML and CSS and can be deployed to any static host, such as GitHub Pages, Cloudflare Pages, or Netlify.

## Deploy

1. Replace every bracketed placeholder in `index.html` and `privacy-policy.html` with accurate institutional information.
2. Review the policy with the responsible privacy/legal and technical teams. Confirm actual data categories, providers, retention periods, security practices, contact details, and the student age groups served; remove or revise any statement that does not match actual practice.
3. Publish the contents of this directory on a static HTTPS host.
4. Confirm both the landing page and `privacy-policy.html` load publicly without authentication. Use the stable HTTPS URL ending in `/privacy-policy.html` as the Meta app's Privacy Policy URL.

Do not submit the policy while placeholders remain. The institution is responsible for ensuring the published notice is complete, accurate, and current.
